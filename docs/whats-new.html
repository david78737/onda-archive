Three ways to use ONDA Replay
Just try it Free — no account needed

Download the app and open a session file. No sign-in, no subscription, no setup.

  • Download ONDA Replay from the Play Store
  • Open a .onda file from the archive below or from someone who shared one with you
  • Follow the transcript as the audio plays, tap any word to jump to that moment
  • Browse ONDA Nile to find published sessions
Record something Contributor — $8.99/mo

Capture a meeting, talk, or idea. Get a searchable transcript back. Build a private catalog.

  • Tap record, speak, tap stop
  • Transcription runs automatically and returns word-level timestamps
  • Tap any word in the transcript to play from that exact moment
  • Tag your sessions, build an index, share .onda files with others
  • Apply to present at a Curator's event using an event code
Publish something Curator — $19.99/mo or $99.99/6mo

Create a station on ONDA Nile. Manage events, approve speakers, publish a body of work.

  • Subscribe as a Curator from the Utilities tab
  • Register your station at the Curator portal
  • Create an event and share the event code with your speakers
  • Review speaker applications, approve or return them
  • Approved speakers record their talks and auto-upload to your station
  • Publish to ONDA Nile — your audience downloads and replays at their own pace
What is new in this build (1.7.15)
🎓
Become a Curator
A new button in Utilities opens a pricing sheet where you can subscribe monthly or every six months. As a license tester, this will complete at $0.00.
🎤
Presenter proxy flow
Approved speakers enter a proxy code, record their talk, and tap Stop. The session auto-uploads to the Curator's station. No file transfer, no manual steps.
🔍
Curator portal navigation
The archive home page now has a Curator Tools section with one-tap links to every admin page: register, station profile, event creation, speaker review, bulk upload.
📺
YouTube to .onda
Paste a YouTube URL, pay $4.99, receive a .onda file by SMS. The pipeline transcribes the audio with Whisper and packages it as a fully navigable session file.
The help system
📖

Every screen has a help page with a numbered map

Tap the help icon on any screen in ONDA Replay and you land on a page showing an annotated screenshot of that exact screen, with numbered callouts for every control. No separate manual. Always current because it lives on the web, not inside the app.

This is also a proof of concept for something bigger: words, images, and audio working together so that content runs at the reader's pace, not the producer's. The help system is the first version of that idea.

What is new on ONDA Nile
🌊
Station model live
Curators can register a station, set a color theme, and publish sessions under a branded banner. The station links back to every presenter who has appeared there.
📅
Event and slot creation
Curators generate event codes and assign session slots. Presenters enter the code in Replay, submit an application card, and wait for approval.
🗳️
Speaker card review
Curators or their coordinators review application cards and approve, return, or hold them. Approved speakers receive a proxy code automatically.
📤
Bulk upload
Upload multiple .onda files to a station at once. Useful for organizations that have an existing archive of recorded content and want to publish it all at once.
