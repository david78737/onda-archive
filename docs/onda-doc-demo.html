How an IT firm delivers this for any client

The system requires no special software on the client side. Every piece of it runs on tools an IT professional already knows.

  1. 1
    Identify the screens users struggle with
    Walk the software with the client. Ask where the support calls come from. That's where the callouts go first.
  2. 2
    Take a screenshot of each screen
    Phone camera or screen capture. No special equipment. One screenshot per screen.
  3. 3
    Number every control on the screenshot
    Every button, field, icon, toggle, and menu gets a number. The user can now locate ① before reading what ① does.
  4. 4
    Write a plain-language explanation for each number
    Large text. No jargon. Written for someone who has never seen this screen. Accessible to seniors, ESL users, first-day employees.
  5. 5
    Publish to a web page
    GitHub Pages hosts it for free. The client gets a URL. That URL can be a QR code on the wall, a link in the software, or a bookmark on every device.
  6. 6
    When anything changes, update one page
    30 seconds from change to fix. Every user, every device, every location — sees the updated help immediately. No support call. No reprinted manual.
